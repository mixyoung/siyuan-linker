# SiYuan Linker（连接互传）

在本地与远程思源笔记服务之间传输笔记和工作空间数据，主要用于连接桌面版与 Docker 部署的思源笔记。

> 从 v0.3.0 起，插件技术 ID 改为 `siyuan-linker`。原 `siyuan-link` 插件的设置不会自动迁移，需要重新配置。

> 本插件会读写思源工作空间文件。使用单笔记或全量传输前，请先备份数据并确认目标服务配置正确。

## 功能

- 将当前笔记连同附件、属性视图数据传输到目标源，并保持笔记路径。
- 将本地工作空间数据全量传输到目标源。
- 将目标源工作空间数据全量拉取到本地。
- 在右侧面板浏览目标源笔记本，按需展开文档树并多选拉取。
- 配置两个目标源并随时切换。
- 可选为传输后的笔记添加只读标记。

DeepSeek、Kimi 网页嵌入以及 AList 相关功能已从本插件移除。本插件聚焦思源服务之间的笔记传输。

## 配置

在插件设置中填写目标思源服务的网址和 API 密钥。网址末尾不要添加 `/`：

- 正确：`http://siyuan.example.com`
- 错误：`http://siyuan.example.com/`

保存后可以使用“验证服务连接”检查配置。

## 使用方式

- **传输当前笔记**：打开目标文档，点击顶栏“数据传输”图标并选择“传输当前笔记”。
- **全量传输/拉取**：在插件设置中执行对应操作。
- **选择性拉取**：打开右侧“目标源笔记”面板，选择笔记本、展开文档树、选择文档并点击“拉取笔记”。

## 历史

- v0.1.x：实现单笔记、全量传输/拉取、多目标源及远程文件树。
- v0.2.0–v0.2.5：曾提供 AList 相关功能，v0.2.7 起拆分移除。
- v0.2.6：曾加入 DeepSeek/Kimi 网页嵌入，后续开发中已移除。
- v0.2.7：移除 AList 功能。
