# SiYuan Linker

**简体中文** · [English](README_en_US.md)

连接两个 SiYuan 实例，在本地端与远程端之间迁移笔记或工作空间数据。

> [!IMPORTANT]
> 当前版本要求 **SiYuan 3.8.2 或更高版本**。正式支持桌面端与独立桌面窗口；浏览器和移动端仍需完成跨域、混合内容和大文件验证。

## 传输模式

### 安全传输（默认）

使用 SiYuan 原生 `.sy.zip` 导出/导入接口。附件、PDF 标注、属性视图及其关联由 SiYuan 内核处理，并自动更新缓存和索引。

安全传输适合独立工作空间，但导入时会重建文档、块和属性视图 ID，不应用于依赖原 ID 的镜像发布流程。SiYuan 原生导出还可能包含所选文档引用的文档、按源端设置包含的子文档、关联属性视图及相关资源，插件会在导入前提示确认这一范围。

### 保留内部 ID（专家模式）

直接复制同源工作空间中的文档文件，仅适用于已经由全量克隆建立共同来源的实例。启用前必须满足：

- 两端 SiYuan 版本完全一致；
- 目标端已经存在相同 notebook ID；
- 文档不包含属性视图；
- 笔记本未加密，并已完成备份。

插件会在写入后调用 v3.8.2 的索引接口并刷新文件树，但这一模式仍不是事务型同步。

## 功能

- 将当前本地文档推送到目标 SiYuan。
- 浏览目标端笔记本和文档树，批量拉取所选文档。
- 在两个一次性工作空间之间执行全量数据迁移。
- 配置两个目标源并快速切换。
- 在传输前检查两端 SiYuan 版本。
- 对空响应、损坏 JSON、代理 HTML 页面和错误 ZIP 给出带接口上下文的错误信息。

## 配置

1. 在目标 SiYuan 的 **设置 → 关于** 中确认 API Token。
2. 在运行插件的本地 SiYuan 中打开 **设置 → 密钥与变量**，创建一个 Secret，例如 `SIYUAN_LINKER_TARGET_1_TOKEN`，值为目标 API Token。
3. 在插件设置中填写目标 URL 和 Secret 名称，而不是 Token 本身。
4. 点击“验证”确认目标版本、认证和笔记本读取能力。

非回环地址默认必须使用 HTTPS。如果只在可信局域网内使用 HTTP，需要显式启用“允许远程 HTTP（不安全）”；Token、笔记和归档会以明文传输。

旧版本曾把 Token 明文保存在插件数据中。升级后会提示迁移；Secret 验证成功时，旧字段会从插件配置文件中清除。

## 使用

- **推送当前文档**：打开文档，点击顶栏双向箭头，再选择“传输当前笔记”。安全模式会使用“源笔记本名称（源 notebook ID）”在目标端稳定复用或创建笔记本，避免同名笔记本混合。
- **拉取所选文档**：打开右侧“目标源笔记”面板，选择目标笔记本和文档后点击“拉取笔记”。
- **全量传输/拉取**：仅用于已备份的空白或一次性工作空间。该操作可能覆盖或混合已有数据，且失败后可能已经产生部分写入。

## 本地安装

将 `package.zip` 解压到：

```text
<SiYuan 工作空间>/data/plugins/siyuan-linker/
```

确保 `plugin.json`、`index.js`、`index.css` 位于目录根部，然后重启 SiYuan 或刷新插件列表。

## 开发

```bash
pnpm install
pnpm validate
pnpm typecheck
pnpm test
pnpm build
```

构建产物位于 `dist/`，发布包为项目根目录的 `package.zip`。

## 安全提示

- 不要在 URL、日志、截图或仓库中暴露 API Token。
- 远程服务应使用 HTTPS；浏览器环境还受 CORS、混合内容和 Private Network Access 限制。
- 全量导入不是双向冲突合并，也没有跨实例事务回滚。
- 任何写入前都应备份两端工作空间，并确认传输方向。
